## Правила именования
`icon_{группа}_{название}_{размер}.svg` → `icon_tools_brush_24.svg`

## Экспорт
- SVG (основной формат, 24 × 24, контурный) — для веба и Figma.
- Иконочный шрифт `pixelforge-icons.woff2` — для быстрого подключения.
- PNG @2× / @3× — только для легаси-мест.

Все иконки использованы в макетах и в UI-китах (`design/export/svg/UI_Kit_*.svg`).

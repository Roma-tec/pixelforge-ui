# Логотип PixelForge

Знак: окружность с линейным градиентом `135° #6C4CF1 → #B14CF1 → #F14CA6`.

| Файл | Вариант | Где применять |
|---|---|---|
| `logo_horizontal_color.svg` | знак + текст, цветной | шапка лендинга, дашборд |
| `logo_horizontal_white.svg` | знак + текст, белый | тёмный фон, тёмная тема |
| `logo_horizontal_dark.svg` | знак + текст, тёмный | светлая тема, документы |
| `logo_mark_color.svg` | только знак, цветной | аватар, фоновые подписи |
| `logo_mark_mono.svg` | только знак, моно | одна краска, печать |
| `logo_app_icon.svg` | знак в квадрате 1024 × 1024 | иконка приложения, favicon |

Минимальный размер: 24 px (знак), 96 px (горизонтальный).
Охранное поле: не менее 0.5 высоты знака.

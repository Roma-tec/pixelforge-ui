# PixelForge — UI/UX дизайн графического редактора

Лабораторная работа **S2G11 «Проект интерфейса программной системы»**, вариант № 3 «Графический редактор».

Проект представляет собой полный комплект UI/UX-дизайна кроссплатформенного графического редактора: от технического задания и исследования аудитории до готовых макетов, UI-китов, диаграмм и материалов для передачи в разработку.

## Работающее веб-приложение

Папка **`site/`** — это **настоящее работающее веб-приложение** (HTML + CSS + JavaScript),
свёрстанное по макетам. Никаких картинок — всё живое: кнопки нажимаются, поля вводятся,
холст рисуется, фильтры применяются, файл скачивается.

**Открыть:** `site/index.html` (карта сайта) → оттуда переход в приложение.
Поток: `login.html` → `dashboard.html` → `editor.html` → экспорт.

### Что реально работает

| Страница | Возможности |
|---|---|
| `login.html` | рельная форма: валидация e-mail и пароля, индикатор надёжности, вкладки «Вход / Регистрация», вход через Google/Apple, восстановление пароля (модалка), аккаунт сохраняется |
| `dashboard.html` | живые карточки проектов из хранилища, поиск, сортировка, фильтры, создание проекта (модалка с пресетами и размером), переименование, дублирование, удаление, пустые состояния |
| `editor.html` | **настоящий редактор**: холст 1080×1080, 12 инструментов, контекстная строка параметров, слои (видимость, блокировка, порядок, переименование, прозрачность, дублирование, удаление), **рисование кистью мышью**, 12 фильтров с живым предпросмотром и интенсивностью, «До/После», история с откатом по шагам, пипетка (берёт цвет с холста), перемещение объектов мышью, зум (− / + / вписать / 100 %), **экспорт в PNG / JPG / WEBP со скачиванием файла**, Ctrl+Z / Ctrl+Shift+Z / Ctrl+S и горячие клавиши инструментов |
| `templates.html` | 12 шаблонов с фильтрами по категориям и поиском; «Использовать» создаёт проект и открывает редактор |
| `export.html` | пресеты платформ (Instagram, Сторис, VK, A4), выбор формата, очередь проектов, запуск экспорта |
| `settings.html` | реальные настройки: три темы, 5 акцентных цветов, масштаб интерфейса, переключатели, редактирование профиля, управление хранилищем, полный сброс |
| `admin.html` | таблица пользователей (роль L3): поиск, фильтр по роли, смена роли, блокировка, метрики |
| `mobile.html` | мобильный интерфейс в рамке телефона: список проектов, шаблоны, мини-редактор с фильтрами и экспортом |
| `screens.html` и др. | витрина макетов: 32 экрана, UI-кит, moodboard, User Flow Map, UML Use-Case |

Все данные хранятся в `localStorage` браузера, поэтому приложение работает офлайн
и не требует сервера.

> **Важно:** для работы фильтров и экспорта откройте сайт через локальный сервер
> (GitHub Pages тоже подходит). При открытии файла двойным щелчком (`file://`)
> часть браузеров блокирует `localStorage`. Запуск локально:
> `cd site && python -m http.server 8000`, затем `http://localhost:8000`.

## Дизайн-токены

```css
:root {
  --accent-500: #6C4CF1;   /* основной акцент */
  --bg-1: #F7F7FA;         /* фон приложения (светлая) */
  --text-1: #0F0F14;       /* основной текст */
  --radius-md: 8px;
  --space-4: 16px;
  --dur-base: 240ms;
}
[data-theme='dark'] {
  --bg-1: #121218;         /* фон приложения (тёмная) */
  --bg-2: #1B1B23;
  --text-1: #F2F2F7;
  --accent-500: #8A73F5;
}
```

Полный набор: [`tokens/tokens.json`](tokens/tokens.json), [`tokens/tokens.css`](tokens/tokens.css).

## Как открыть

1. **Приложение:** запустите локальный сервер в папке `site/` (`python -m http.server 8000`) и откройте `http://localhost:8000`.
2. **PDF отчёта:** откройте `design/export/PixelForge_Makety.pdf` (макеты) и `design/export/PixelForge_Diagrammy.pdf` (диаграммы).
3. **Быстрый просмотр:** папка `design/export/screens/` — PNG каждого экрана (тёмная и светлая темы).
4. **Figma:** перетащите SVG-файлы из `design/export/svg/` в файл Figma — они импортируются как векторные слои с редактируемым текстом.
5. **Токены для кода:** подключите `tokens/tokens.css` или импортируйте `tokens/tokens.json`.

# Доступность (Accessibility)

## Целевой уровень
**WCAG 2.1 AA**.

| Критерий | Требование | Как проверяем |
|---|---|---|
| Контраст текста | ≥ 4.5:1 (обычный), ≥ 3:1 (крупный ≥ 18.66 px bold) | плагин Stark в Figma |
| Контраст интерфейсных элементов | ≥ 3:1 (границы полей, иконки, чекбоксы) | Stark |
| Размер области нажатия | ≥ 44 × 44 px (мобайл), ≥ 32 × 32 px (десктоп) | ручная проверка |
| Видимый фокус | кольцо 2 px, цвет `--info`, отступ 2 px | Tab-проход по экрану |
| Навигация с клавиатуры | все действия доступны без мыши | Tab / Shift+Tab / Enter / Esc |
| Порядок фокуса | совпадает с визуальным порядком (слева-вправо, сверху-вниз) | Tab-проход |
| Не только цветом | состояние дублируется иконкой, подписью или формой | чек-лист по компонентам |
| Движение | при `prefers-reduced-motion` анимации ≤ 60 мс или отключены | настройка + медиазапрос |
| Масштабирование текста | интерфейс не ломается при масштабе 150 % | встроенная настройка «Масштаб» |
| Альтернативы для иконок | у каждой иконки-кнопки — `aria-label` | разметка |

## ARIA-роли ключевых компонентов
| Компонент | Роль |
|---|---|
| Панель инструментов | `toolbar` |
| Кнопка-инструмент | `button` + `aria-pressed` |
| Список слоёв | `tree` / `treeitem` + `aria-expanded`, `aria-level` |
| Вкладки панелей | `tablist` / `tab` / `tabpanel` |
| Слайдер | `slider` + `aria-valuenow`, `aria-valuemin`, `aria-valuemax` |
| Модальное окно | `dialog` + `aria-modal="true"` + фокус-трап |
| Тост | `status` (вежливое объявление) |
| Ошибка поля | `aria-invalid="true"` + `aria-describedby` |
| Прогресс | `progressbar` + `aria-valuenow` |
| Холст | `application` + текстовое описание текущего состояния |

## Особые случаи
- Дальтоники: палитра фильтров и маркеры слоёв используют и цвет, и иконку/контур.
- Тёмная тема: акцент заменяется на `#8A73F5` — иначе контраст на тёмном фоне падает ниже 4.5:1.
- Все числовые значения дублируются текстом (не только ползунком).
